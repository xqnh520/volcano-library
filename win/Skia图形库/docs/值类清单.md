# Skia 封装 · 值类（结构体）清单与 x64 内存布局

> **本文件是工程师写"字段偏移"与"字节集类缓冲大小"的唯一依据。**
> 生成方式：从 `deps\skia\include\c\*.h` 逐个提取 `typedef struct{...}` 原始定义，按 **MSVC x64（LLP64）默认 8 字节对齐** 计算偏移与尺寸；已确认全部 43 个头文件中**没有 `#pragma pack` / `__declspec(align)`**，所以默认对齐规则即为真实布局。
> 类型宽度约定：`bool/char/uint8_t`=1；`int16_t/uint16_t`=2；`int/int32_t/uint32_t/float/枚举`=4；`size_t/uint64_t/int64_t/intptr_t/任何指针`=8。
> 关联文档：`架构设计.md`（值类方案 §三）、`命名映射-批次1.md`（方法名权威）。

## 五、必须注意的 8 个布局陷阱

1. **`bool` 只占 1 字节，后面有填充**。例如 `sk_sampling_options_t.fUseCubic` 在偏移 4，`fCubic` 从 8 开始（中间 5/6/7 三字节是填充）。**不要用 4 字节 int 写 bool 字段**，否则会覆盖填充区甚至下一字段。写法：`p->fUseCubic = (@<启用> != 0);`
2. **`size_t` 是 8 字节**。`sk_codec_options_t.fMaxDecodeMemory` 在偏移 24；`sk_runtimeeffect_uniform_t.fOffset` 在 16。用 `(size_t)` 强转火山 `变整数`。
3. **枚举一律 4 字节**（C 枚举按 int）。`sk_codec_frameinfo_t` 里 bool 与枚举交错，偏移是 0/4/8/12/16/20/24/28 —— 中间 9~11、13~15、17~19、21~23 **全是填充**。
4. **`sk_imageinfo_t` 需要 8 字节对齐**（成员含指针，对齐=8）。`取空白字节集类` 的堆内存满足 8 字节对齐，可安全强转；**但不要把它放在自建结构体的任意偏移上**。
5. **`sk_document_pdf_datetime_t` 只有 10 字节**，且对齐是 2（成员最大宽度是 int16_t/uint16_t）。缓冲取 10 字节即可，不要取 12。
6. **`sk_codec_frameinfo_t` 是 44 字节**（不是 48）：末尾 `sk_irect_t fFrameRect` 在 28，占 16 字节到 44，整体对齐 4 恰好整除。
7. **`sk_matrix_t` 的成员顺序不是直觉的 3×3**：第一行是 `scaleX, skewX, transX`，第二行 `skewY, scaleY, transY`，第三行 `persp0, persp1, persp2`。平移在 transX(8)/transY(20)。**把平移写到 persp0/persp1 会让图元钉在原点。**
8. **`sk_fontarguments_variation_axis_t` 的成员名 `min`/`def`/`max`** 与 C 宏冲突；已用 `NOMINMAX` 规避，工程内不得再 `#define min/max`。另 `sk_runtimeeffect_*_t` 的 `fName` 是 `const char*`（UTF-8），转文本用 `@an<CVolString>`。

### 校验依据
- `sk_colorspace_transfer_fn_t` / `_primaries_t` / `_xyz_t` 均为 `typedef struct { float ... } name;` 的**纯 float 值结构**，见 `sk_types.h:912-943`。
- `sk_runtimeeffect_uniform_t` / `child_t` 见 `sk_types.h:1116-1130`；`uniform_t` 的 `fFlags` 在偏移 32 占 4 字节，结构体对齐为 8，故总长 40（尾部 4 字节填充，**不是 36**）。
- `sk_colorspace_icc_profile_t` 是 `typedef struct sk_colorspace_icc_profile_t sk_colorspace_icc_profile_t;`（不透明声明，`sk_types.h` typedef 区），**只能当句柄**，绝不能按值类处理。
- ⚠ `Skia效果变量` / `Skia效果子项` 的 `fName` 是 `const char*`（UTF-8，**无结尾 0 保证**），必须用 `fNameLength` 截取，不能直接当 C 字符串用。
