  ⚠ **6 个 `加引用` 的 const 修饰各不相同，必须逐个照头文件写**（下表已逐个 grep `deps\skia\include\c\*.h` 核对，2026-10-30 复核）：

  | 方法 | 真实原型 | 嵌入行强转 |
  |---|---|---|
  | `Skia数据.加引用` | `sk_data_ref(`**`const`**` sk_data_t*)` | `(const sk_data_t*)` |
  | `Skia图片.加引用` | `sk_picture_ref(sk_picture_t*)` ← **非 const** | `(sk_picture_t*)` |
  | `Skia文字块.加引用` | `sk_textblob_ref(`**`const`**` sk_textblob_t*)` | `(const sk_textblob_t*)` |
  | `Skia着色器.加引用` | `sk_shader_ref(sk_shader_t*)` ← **非 const** | `(sk_shader_t*)` |
  | `Skia遮罩滤镜.加引用` | `sk_maskfilter_ref(sk_maskfilter_t*)` ← **非 const** | `(sk_maskfilter_t*)` |
  | `Skia顶点.加引用` | `sk_vertices_ref(sk_vertices_t*)` ← **非 const** | `(sk_vertices_t*)` |

  另：`sk_image_ref(const sk_image_t*)`、`sk_blender_ref(sk_blender_t*)`、`sk_colorspace_ref(sk_colorspace_t*)`（批次2/3 原有，非本补丁范围）。**结论：const 只能逐个查，不能按"只读就加 const"推断。**
- `取无符号八位/十六位/三十二位`：`@ (sk_stream_read_u8((sk_stream_t*)@sn<this>.@n<Skia流.对象指针>, (uint8_t*)@<结果数据>.GetPtr()) != 0)`（其余两条把 `uint8_t` 换成 `uint16_t`/`uint32_t`）
- `写数据`：**必须写成普通方法**（要局部变量算出长度，避免同一参数在一行内引用两次）
  变量 数据尺寸 <类型 = 变整数>
  数据尺寸 = 取字节集长度 (@<数据>)
  @ (sk_wstream_write((sk_wstream_t*)@<流句柄>, (const void*)@<数据>.GetPtr(), (size_t)@<数据尺寸>) != 0)
  （`@<数据>` 在普通方法里要先用 `变量 缓冲 <类型 = 字节集类>` / `缓冲 = 数据` 接住，再对 `@<缓冲>` 取 `.GetPtr()`）
- `取已写字节数` 返回 `size_t` → 方法类型 `变整数`，嵌入行 `@ (intptr_t)sk_wstream_bytes_written((sk_wstream_t*)...)`
- `是否已打开`（两个）：`sk_stream_filestream_t*` / `sk_wstream_filestream_t*`，**注意不是 `sk_filestream_t`/`sk_filewstream_t`**（见批次2 附录的类型名纠正）。命名上**不叫** `是否有效`（基类 `Skia流` 已占用该方法名且是内联折叠方法）
- `取颜色空间`：返回 `sk_colorspace_t*`，包装成 `Skia颜色空间` 时**必须 `是否拥有句柄 = 假`**
