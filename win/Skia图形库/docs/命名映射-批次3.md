- `sk_runtimeeffect_make_shader / make_color_filter / make_blender` 的 children 参数类型是 **`sk_flattenable_t**`**（不是 `sk_runtimeeffect_t**`，也不是 `sk_shader_t**`）。`sk_flattenable_t` 是 `sk_types.h:79` 的不透明基类声明。火山侧统一用 `字节集类` 承载"指针数组"（每个指针 8 字节），写指针时强转为 `(sk_flattenable_t**)`。

## ⚠ 包级风险提示：本批次 5 个类"只有 unref，没有 ref"

原生只导出 `unref`，因此这些对象在火山侧的引用计数**只有一份**：

| 类 | 有 ref？ | 后果 |
|---|---|---|
| `Skia着色器` | ✗（`sk_shader_ref` 未导出） | 一个着色器只能安全地交给一个画笔 |
| `Skia图像滤镜` | ✗（原生根本没有 ref 函数） | 同上 |
| `Skia颜色滤镜` | ✗（原生根本没有 ref 函数） | 同上 |
| `Skia遮罩滤镜` | ✗（`sk_maskfilter_ref` 未导出） | 同上 |
| `Skia运行时效果` | ✗（原生根本没有 ref 函数） | 运行时效果本身可多次 `取着色器`，但自身只释放一次 |

`Skia混合器` 与 `Skia颜色空间` 是例外：两者 `ref`/`unref` 都导出，**可以** `加引用` 后交给多个画笔。

**必须写进这 5 个类的类注释（原样抄）**：
> **「本类对象只持有一份引用（原生只导出 unref，没有 ref）。置入画笔后画笔会自行加引用，但火山侧句柄只能 `释放` 一次；释放后再把同一句柄置入第二个画笔是未定义行为。保守用法：一个对象只置入一个画笔，置入后不再 `释放`、不再复用；需要给第二个画笔用就重新 `新建`。」**
