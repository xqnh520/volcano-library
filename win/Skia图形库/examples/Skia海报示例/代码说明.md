# Skia 海报示例 · 代码说明

一个 190 行的完整示例：**用 Skia图形库 模块画一张 800×600 海报，编码成 PNG 保存**。
编译 `0 错误 0 警告`，运行输出 46 KB PNG（压缩等级 6）。

效果图：`skia演示.png`

---

## 这个示例演示了什么

| 能力 | 用到的 API |
|---|---|
| 创建画布（直接画进自己的内存） | `Skia图像信息.新建` + `Skia画布.新建_按像素` |
| 纯色填充 | `画布.清空 (颜色)` |
| 画笔状态 | `Skia画笔.新建 / 置颜色 / 置样式 / 置线宽 / 置抗锯齿` |
| 圆形 | `画布.绘制圆 (x, y, r, 画笔)` |
| 圆角矩形 | `画布.绘制圆角矩形_按半径 (矩形, 横半径, 纵半径, 画笔)` |
| 几何值类 | `Skia矩形.置边界 (左, 上, 右, 下)` |
| 中文文字 | `Skia字体样式.新建` → `字体管理.按族名取字形` → `Skia字体.新建_按字形` → `画布.绘制简单文字` |
| 文字度量 | `字体.取文字宽度 ("...")` |
| PNG 编码 | `Skia像素图.新建_按参数` → `Skia编解码器.编码PNG`（配合 `Skia动态内存写流`） |
| 句柄生命周期 | 每个 `新建` 配对 `释放` |

## 代码骨架（六步）

```火山
// ① 准备像素缓冲（BGRA 字节序 = Windows DIB 顺序）
宽 = 800
高 = 600
行字节 = 宽 * 4
像素缓冲 = 取空白字节集 (宽 * 高 * 4)
图像信息 = Skia图像信息.新建 (宽, 高)

// ② 让火山把缓冲地址交给 C（内联行，这是唯一需要写 C 的地方）
@ @<像素地址> = (intptr_t)@<像素缓冲>.GetPtr();

// ③ 建画布：画布直接写进上面那块缓冲，不复制
画布 = Skia画布.新建_按像素 (图像信息, 像素地址, 行字节, 空表面属性)

// ④ 画：颜色是 0xAARRGGBB 装进有符号 32 位整数
画布.清空 (-14800316)                        // 0xFF1E2A44 深蓝
画笔 = Skia画笔.新建 ()
画笔.置抗锯齿 (真)
画笔.置颜色 (1090519039)                     // 0x40FFFFFF 半透明白
画布.绘制圆 (680.0, 80.0, 210.0, 画笔)

// ⑤ 画文字（字体链路：样式 → 字形 → 字体）
字体样式 = Skia字体样式.新建 (700, 5, 0)      // 粗细700 宽度5 倾斜0
字形 = 字体管理.按族名取字形 ("SimHei", 字体样式)
字体标题 = Skia字体.新建_按字形 (字形, 44.0, 1.0, 0.0)
文字字节 = 文本到UTF8 ("Skia 图形库", 假)     // 文字参数是字节集，不是文本
画布.绘制简单文字 (文字字节, 0, 60.0, 145.0, 字体标题.取句柄, 画笔)

// ⑥ 编码 PNG 并写文件
PNG选项.置ZLib等级 (6)                       // 不设会输出未压缩 PNG（1.9MB → 46KB）
像素图 = Skia像素图.新建_按参数 (图像信息, 像素地址, 行字节)
写流 = Skia动态内存写流.新建 ()
Skia编解码器.编码PNG (写流, 像素图, PNG选项)
PNG长度 = 写流.取已写字节数 ()
@ @<PNG长度整数> = (int)@<PNG长度>;          // size_t → int
PNG数据 = 取空白字节集 (PNG长度整数)
写流.复制到 (PNG数据)
写到文件 ("skia演示.png", PNG数据)
```

## 写这个示例时踩到的 6 个坑（都是真实报错）

| 坑 | 报错 | 正确做法 |
|---|---|---|
| 窗口成员名 `信息框` | `发现了重复的名称"信息框"` | MFC 窗口基类已占用，改叫 `输出框` |
| 事件方法里写 `返回` | `返回值被定义为"整数", 但"返回"语句没有提供对应数据` | 写 `返回 (0)`，且所有分支 + 方法末尾都要返回 |
| 对值类调 `释放` | `没有找到所指定的方法名称"释放"` | `Skia图像信息` / `Skia矩形` 是值类，没有 `释放`；只有句柄类才有 |
| `变整数` 传给 `取空白字节集` | `从"长整数"转换到"整数"时存在精度损失` | 先用内联行转 `(int)`，火山没有可直接调用的 `到整数 ()` |
| PNG 编码选项默认全 0 | 图能出，但 **1.9 MB**（未压缩） | `PNG选项.置ZLib等级 (6)`，同样体积降到 46 KB |
| 文字太长 | 超出画布右边被裁掉，**不报错** | 用 `字体.取文字宽度 ("...")` 先量再定位置，或提前缩短文案 |

## 想改成自己的图，只需要动三处

1. **尺寸**：改 `宽 = 800` / `高 = 600`（行字节和缓冲大小会自动跟着算，因为代码里是 `宽 * 4`）
2. **内容**：改绘制块（清空色、圆、方块、文字文案）
3. **配色**：颜色值换成自己的 `0xAARRGGBB`，用下面的方式换算成有符号数

```
有符号值 = 无符号值 - 4294967296   （当无符号值 >= 2147483648 时）
例：0xFF1E2A44 = 4280170052 - 4294967296 = -14800316
    0x40FFFFFF = 1090519039（小于 2^31，直接就是正数）
```

或者干脆不换算，用内联行写十六进制：

```火山
@ @<某个整数变量> = (int)0xFF1E2A44;
```
