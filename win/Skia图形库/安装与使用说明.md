## 第二步：在你的工程里引用模块

### 方式一：手工改工程文件（最可靠）

用文本编辑器打开你的 `.vprj`，在「模块」那个 child_filter 里加一个 filter：

```
filter3
{
    collapsed = true
    files.num_files = 8
    group_file_name = "*plugins\\vprj_win\\classlib\\user\\Skia图形库\\skia.vgrp"
    name = Skia图形库
}
```

并把上层的 `num_child_filters` 加 1（例：原为 2 就改成 3）。

> `*plugins\...` 是火山的根目录前缀，写死它就不怕工程放在哪。

### 方式二：IDE 里添加

打开工程 → 在「模块」节点上右键 → 添加模块组 → 选到
`D:\Voldev\plugins\vprj_win\classlib\user\Skia图形库\skia.vgrp`。

### 引用后必须确认的一件事

工程属性里 **目标平台 = x64**、**静态运行时库 = 真**。
模块只提供 x64 导入库，选 32 位会链接失败。

## 第三步：最小可运行示例

```火山
// 1. 准备一块 ARGB 像素缓冲（BGRA 字节序 = Windows DIB 顺序）
变量 缓冲 <类型 = 字节集类>
缓冲 = 取空白字节集 (64 × 64 × 4)

// 2. 图像信息 + 画布
变量 信息 <类型 = Skia图像信息>
信息 = Skia图像信息.新建 (64, 64)          // 默认 BGRA_8888 + PREMUL
变量 画布 <类型 = Skia画布>
画布 = Skia画布.新建_按像素 (信息, 缓冲.取地址 (), 64 × 4)

// 3. 画笔（颜色是 0xAARRGGBB 装进有符号 32 位整数）
变量 画笔 <类型 = Skia画笔>
画笔 = Skia画笔.新建 ()
画笔.置颜色 (-16776961)                     // 0xFF0000FF 不透明蓝
画笔.置线宽 (4.0)
画笔.置样式 (1)                             // 1 = 描边

// 4. 绘制
画布.清空 (-1)                              // 0xFFFFFFFF 白底
画布.绘制矩形 (Skia矩形.新建 (8, 8, 56, 56), 画笔)

// 5. 用完释放（必须）
画布.释放 ()
画笔.释放 ()
信息.释放 ()

// 此时 缓冲 里就是渲染结果，可直接贴到窗口/存成 BMP
```

文字绘制（多两步，注意字体样式不能传空）：

```火山
变量 样式 <类型 = Skia字体样式>
样式 = Skia字体样式.新建 (400, 5, 0)        // 粗细400 宽度5 倾斜0
变量 管理器 <类型 = Skia字体管理>
管理器 = Skia字体管理.取默认 ()
变量 字形 <类型 = Skia字形>
字形 = 管理器.按族名取字形 ("SimHei", 样式)
变量 绘制字体 <类型 = Skia字体>
绘制字体 = Skia字体.新建_按字形 (字形, 24)
变量 宽 <类型 = 小数>
宽 = 绘制字体.取文字宽度 ("中")              // 实测 24
画布.绘制简单文字 (文本到UTF8 ("中", 假), 0, 8, 44, 绘制字体.取句柄, 画笔)
// 注意 取句柄 是属性读，不加括号
```

## 最容易踩的五个坑

| 坑 | 表现 | 正确做法 |
|---|---|---|
| **颜色写成 0** | 画了等于没画 | 颜色是 `0xAARRGGBB` 有符号整数：不透明黑 `-16777216`、白 `-1`、红 `-65536`、蓝 `-16776961`。`0` 是**全透明黑** |
| **句柄忘了释放** | 泄漏（不崩） | 每个 `新建` 配一个 `释放 ()`。`类_清理` 故意不释放，因为火山值语义会复制对象 |
| **裁剪忘了恢复** | 后面全画不出来，无报错 | `保存状态 () → 裁剪矩形 (区域, 1, 真) → 绘制 → 恢复状态 ()`。第 2 参数 `1` 才是"取交"，`0` 是"挖去" |
| **`取句柄 ()` 加了括号** | 编译报「没有找到所指定的方法名称」 | `取句柄` 是属性读，**不加括号**：`字体.取句柄` ✅。而 `取文字宽度 ()`、`新建 ()`、`释放 ()` 是普通方法，**必须加括号** |
| **float 数组用 `置字节集单精度小数` 填** | 静默全 0，效果等于没设 | 必须内联 C 写：`@ ((float*)@<数据>.GetPtr())[@<序号>] = (float)@<值>;`。涉及颜色矩阵(20)、虚线间隔、多边形点、绘制多点、映射多点、矩阵卷积 |

## 能力边界（做不到什么）

| 做不到 | 原因 |
|---|---|
| 文字居中/右对齐、LCD 子像素 | 这些能力在 `sk_compatpaint_*`，上游未公开头文件 |
| GPU 渲染（Ganesh / Graphite） | 按 CPU 软件光栅定位；GPU 路径需 D3D12/Vulkan 设备句柄 |
| Lottie 动画 | `skottie_*` 未纳入本轮 |

另有 5 项**未验证**（文件流实际读写、PDF 输出正确性、文字无像素断言、SkSL 着色结果、22 个带裁剪参数的滤镜方法），详见 `README.md` §5 与 `docs\` 内文档。
