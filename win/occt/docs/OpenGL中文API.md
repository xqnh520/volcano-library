# OpenGL / OpenGl_* 中文 API 说明

本文说明 OCCT 8.0 火山封装中的 OpenGL 相关中文类：底层 `gl*` 接口（`OCCTOpenGL*`）与 OCCT `OpenGl_*` / `Graphic3d_*` 对象封装。所有类均位于 `火山.OCCT二维` 包，源码见 `src/occt_2d.wsv`，原生桥接见 `native/occt_2d_bridge.cpp` / `.hpp`。

## 二、通用规则

- 每个火山对象保存一个原生指针（`对象指针`）。`创建`/`从*` 等工厂产生的对象需要在使用结束后调用 `释放()`（基类方法），或由宿主对象析构回收。
- **上下文指针参数**：凡是以 `参数 上下文指针 <类型 = 变整数>` 出现的方法，都要求传入 OCCT `OpenGl_Context*`（即 `OCCTOpenGL设备上下文` 的 `对象指针`），并且该上下文必须处于“当前”状态，否则 GPU 相关操作会失败或抛异常被桥接吞掉。
- **非拥有指针**：`OCCTOpenGL外观.图形外观指针`、`OCCTOpenGL组.取OpenGL外观指针`、`取OpenGL结构指针`、`取图形外观指针` 返回的是**非拥有**原始指针（`变整数`），不要用它们构造可释放对象，也不要手动释放。
- **后端下转**：`OpenGl_Structure/Group/Aspects` 只能由对应的 `Graphic3d_*` 对象在 **OpenGL 显示驱动** 下创建后下转获得（`取OpenGL*`）。若驱动不是 `OpenGl_GraphicDriver`，下转返回 `空`。
- **释放 token**：外部通过原生 `occt2d_delete(<token>, 指针)` 释放时使用的类型标记：`gl_context`、`gl_device_context`（空操作，非拥有）、`opengl_view`、`opengl_window`、`opengl_shader_manager`、`opengl_shader_program`、`opengl_texture`、`opengl_framebuffer`、`g3d_structure_manager`、`g3d_structure`、`g3d_aspects`、`opengl_structure`、`opengl_aspects`、`g3d_group`、`opengl_group`。火山侧一般直接调用对象的 `释放()`。

## 三、底层 GL 接口

### `OCCTOpenGL常量`
存放常用 `GL_*` 常量（清屏位、枚举、格式等），供 `OCCTOpenGL` 方法直接引用。

### `OCCTOpenGL`（静态方法）
基于 Windows GL 1.1 与运行时加载的扩展，涵盖：

- 状态与清屏：`清屏`、`清屏颜色`、`清屏深度`、`清屏模板`、`颜色掩码/深度掩码/模板掩码`、`启用`、`禁用`、`是否启用`、`取错误`。
- 缓冲：`指定绘制缓冲`、`指定读取缓冲`、`指定绘制缓冲数组`。
- 固定管线状态：`深度函数`、`深度范围`、`混合函数`、`透明测试函数`、`剔除面`、`正面绕序`、`着色模式`、`多边形模式`、`多边形偏移`、`线宽`、`点大小`、`裁剪矩形`、`视口`、`像素存储`。
- 矩阵与变换：`矩阵模式`、`置单位矩阵`、`载入矩阵单精度/双精度`、`乘矩阵单精度/双精度`、`压入矩阵`、`弹出矩阵`、`平移`、`平移双精度`、`旋转`、`缩放`、`正交投影`、`透视投影`。
- 立即模式绘制：`开始图元`、`结束图元`、`顶点2/3单精度`、`顶点2/3双精度`、`颜色3/4单精度`、`颜色3/4字节`、`法线3单精度/双精度`、`纹理坐标2单精度`。
- 客户端数组与 VBO：`启用/禁用客户端数组`、`顶点指针`、`颜色指针`、`法线指针`、`纹理坐标指针`、`绘制数组`、`绘制索引`、`绑定缓冲`、`缓冲数据`、`缓冲子数据`、`绑定顶点数组`、`启用/禁用顶点属性数组`、`顶点属性指针`、`生成缓冲`、`删除缓冲`、`生成/删除顶点数组`。
- 纹理：`生成纹理`、`删除纹理`、`绑定纹理`、`激活纹理单元`、`纹理图像二D`、`纹理子图像二D`、`纹理参数整数`、`纹理参数小数`、`取纹理参数整数2`、`生成多级贴图`、`矩形`。
- 着色器（GLSL）：`创建着色器`、`设置着色器源码`、`编译着色器`、`取着色器参数`、`取着色器日志`、`删除着色器`、`创建程序`、`附加/分离着色器`、`链接着色程序`、`取程序参数`、`取程序日志`、`使用程序`、`删除程序`、`取统一变量位置`、`取属性位置`、`绑定属性位置`、`置统一变量1整数`、`置统一变量1/2/3/4小数`、`置统一变量1整数数组`、`置统一变量3/4小数数组`、`置统一矩阵3/4小数数组`。
- FBO/RBO：`绑定帧缓冲`、`帧缓冲纹理二D`、`检查帧缓冲状态`、`绑定渲染缓冲`、`渲染缓冲存储`、`帧缓冲渲染缓冲`、`位块传送帧缓冲`、`生成/删除帧缓冲`、`生成/删除渲染缓冲`。
- 读取与字符串：`取字符串`、`取整数`、`取整数索引`、`取小数`、`取逻辑值`、`读取像素`、`读取像素文本`、`完成`、`刷新`。

### `OCCTOpenGL上下文`
封装一个可供底层 GL 使用的当前上下文（自建隐藏窗口，无需外部 HWND）：

| 方法 | 说明 |
|---|---|
| `创建原生` | 在给定 HWND 上创建 GL 上下文 |
| `创建离屏(宽, 高)` | 创建隐藏窗口离屏上下文，返回 `OCCTOpenGL上下文` |
| `设为当前` / `是否当前` / `解除当前` | 切换当前上下文 |
| `交换缓冲` | SwapBuffers |
| `取设备句柄` | 返回底层 GL 设备句柄 |

## 四、OCCT `OpenGl_*` 封装

工厂：`从图形驱动(驱动)` 取共享上下文，`从指针(指针)` 包装既有上下文。

## 五、`Graphic3d_*` 与 `OpenGl_*` 结构链路

链路：`OCCT结构管理器` → `OCCT图形结构` → `OCCT图形组` → 设置外观；下转得到 `OCCTOpenGL结构` / `OCCTOpenGL组` / `OCCTOpenGL外观`。

### `OCCT结构管理器`（`Graphic3d_StructureManager`）
工厂：`从查看器(V3D查看器)`、`从图形驱动(图形驱动)`（无需查看器，适合离屏）。成员：`是否有效`。

### `OCCT图形结构`（`Graphic3d_Structure`）
工厂 `创建(结构管理器)`。成员：`显示`、`擦除`、`清除(销毁内容)`、`置可见`、`是否可见`、`是否已显示`、`置Z层`、`置显示优先级`、`显示优先级`、`取OpenGL结构()`。

### `OCCT图形组`（`Graphic3d_Group`）
工厂 `创建(图形结构)`。成员：`是否有效`、`无图元`（即 `IsEmpty`）、`是否已删除`、`清除(更新管理器)`、`移除`、`置组外观(外观)`、`置图元外观(外观)`、`取所属结构()`、`取OpenGL组()`。

> 注：`是否为空` 继承自基类，故此处空判断命名为 `无图元`。

### `OCCT图形外观`（`Graphic3d_Aspects`）
工厂 `创建()`。成员：`是否有效`、`着色模型`（0 无光照/1 平面/2 高洛德/3 冯氏/4 PBR）、`置着色模型`、`取OpenGL外观()`。

### `OCCTOpenGL结构`（`OpenGl_Structure`）
由 `OCCT图形结构.取OpenGL结构()` 产生。成员：`是否有效`、`清除(上下文指针)`、`置Z层`、`取消高亮`、`修改状态`、`重置修改状态`、`释放资源(上下文指针)`、`释放GL资源(上下文指针)`。

### `OCCTOpenGL组`（`OpenGl_Group`）
由 `OCCT图形组.取OpenGL组()` 产生。成员：`是否有效`、`取OpenGL外观指针`（非拥有）、`取OpenGL结构指针`（非拥有）、`外观着色模型`、`外观标记大小`、`取图形外观指针`（非拥有）、`释放资源(上下文指针)`。

### `OCCTOpenGL外观`（`OpenGl_Aspects`）
由 `OCCT图形外观.取OpenGL外观()` 产生。成员：`是否有效`、`图形外观指针`（非拥有）、`着色模型`、`置无光照`、`标记大小`、`有点精灵(上下文指针)`、`释放资源(上下文指针)`。

## 六、用法示例

### 1. 底层 GL 离屏渲染
```text
变量 上下文 = OCCTOpenGL上下文.创建离屏(320, 200)
上下文.设为当前()
OCCTOpenGL.视口(0, 0, 320, 200)
OCCTOpenGL.清屏颜色(0.1, 0.2, 0.3, 1.0)
OCCTOpenGL.清屏(OCCTOpenGL常量.颜色缓冲位)
OCCTOpenGL.完成()
调试输出(OCCTOpenGL.读取像素文本(0, 0))
上下文.释放()
```

### 2. 结构 → 组 → 外观（离屏，无需查看器）
```text
变量 显示连接 = OCCT显示连接.创建()
变量 驱动 = OCCTOpenGL图形驱动.创建(显示连接)
变量 结构管理器 = OCCT结构管理器.从图形驱动(驱动)
变量 结构 = OCCT图形结构.创建(结构管理器)
变量 组 = OCCT图形组.创建(结构)
变量 外观 = OCCT图形外观.创建()
外观.置着色模型(2)
组.置组外观(外观)
变量 后端组 = 组.取OpenGL组()
调试输出(后端组.外观着色模型)   ' 2
' 释放顺序：组 → 结构 → 管理器 → 驱动 → 显示连接
```

### 3. 纹理 / 帧缓冲（需 OCCT 设备上下文）
```text
变量 纹理 = OCCTOpenGL纹理.创建()
变量 帧缓冲 = OCCTOpenGL帧缓冲.创建()
' 设备上下文需先处于当前状态
纹理.创建资源(设备上下文.对象指针)
帧缓冲.初始化(设备上下文.对象指针, 512, 512, 0x8058, 0x81A5, 0)
```
